<h1 align="center">SkillArchive</h1>

<p align="center">
  A native macOS app that backs up and installs <b>Agent Skills</b> across every AI coding agent installed on your Mac.
</p>

<p align="center">
  <img src="docs/screenshot.png" alt="SkillArchive Screenshot" width="800" />
</p>

## Features

- **Cross-agent scan** — finds every skill in each agent's global folder and project-local folders.
- **One canonical store** — single folder (on iCloud Drive) that every agent installs from.
- **Promote / Back up / Install** — manage skills individually or in bulk.
- **Per-agent install targets** — select which agents participate in installs.

## Installation

### Homebrew
```bash
brew tap mrKangHo/tap
brew install skillarchive
```

Or direct cask:
```bash
brew tap mrKangHo/SkillArchive https://github.com/mrKangHo/SkillArchive
brew install --cask skillarchive
```

## Requirements

- macOS 13 (Ventura) or later
